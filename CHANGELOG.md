# Changelog

All notable changes to the Construction Platform API are documented here, following [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). There are no version tags yet, so releases are listed by date.

### Step 18 — Tax
- **Tax settings** (module `tax`, off by default): `GET / PATCH /tax/settings` — on / off, authority PRA / SRB / KPRA / ICT (default rates 16 / 15 / 15 / 16 % only pre-fill), rate, invoice label, company NTN + STRN, the usual client WHT %; switching on needs an authority and a rate (`400 TAX_SETTINGS_INCOMPLETE`). Every change is audited and recalculates DRAFT invoices.
- **Project tax override**: `GET / PATCH /projects/:id/tax` — INHERIT / ON / OFF plus authority / rate for a project in another province; the answer gives the effective tax and the company WHT default.
- **Output tax on invoices**: tax = round half-up (taxable base × rate) on the paisa, once per invoice; taxable base = every line except owner-recoverable purchases (RECOVERABLE invoices are no longer taxed). Issuing freezes the tax snapshot (`taxableBasePaisa`, `taxAuthority`, rate, label, `sellerNtn`, `sellerStrn`, `buyerNtn`) — later setting changes never alter issued invoices. The invoice PDF prints the taxable value, NTN / STRN and the client's NTN.
- **Client WHT on payments**: `whtRatePercent` (works the WHT out as r % of the gross), `whtCertificateNo` / `whtCertificateDate` / `whtCertificateAttachmentId`; new errors `WHT_RATE_MISMATCH`, `WHT_TOO_HIGH`, `WHT_CERTIFICATE_WITHOUT_WHT`; WHT also allowed when only the project has tax switched on. `PATCH /payments/:id/wht-certificate` adds the certificate later. Payment answers gain `grossPaisa`, `whtRatePercent`, `whtCertificate`; the receipt PDF shows the certificate number.
- **Tax reports** (same CSV / Excel / PDF pipeline): `GET /reports/wht-summary` (per client × month: gross, cash, WHT, WHT %, certificates received / missing) and `GET /reports/tax-invoice-register` (taxable value, rate, tax, authority, status; cancelled listed but not counted). Default period = the current tax year (1 Jul – 30 Jun). Need `tax.view` + `fields.amounts`.
- Clients have an optional `ntn` (create / update / answers).
- Permissions `tax.view` (Accountant, Administrator) and `tax.settings.manage` (Administrator).
- Migration `20261109100000_tax` (enums `TaxAuthority`, `ProjectTaxMode`; columns on TenantSettings, Project, Client, Invoice, ClientPayment — no new tables). Seed `prisma/seedTax.ts`: Malik stays tax OFF (client NTN + STRN filled in); `SEED_TAX_DEMO=1` switches PRA 16 % on.

Rupee keys left out without `fields.rates` (material), `fields.amounts` + `fields.rates` (cost), `fields.amounts` / `fields.contract` (burn rate), all four for the projected margin. ### Added
- **Contract value from the estimate**: `GET /projects/:id/estimate` returns `contractSuggestion` (fields.contract + fields.rates) — FULL: cost × (1 + finishing %) × (1 + margin %), GREY: cost × (1 + margin %), both to the nearest Rs 1,000; LABOR_ONLY: a rate = labour × (1 + margin %) ÷ covered sq ft to the nearest Rs 5 — with where the percentages come from (COMPANY / PROJECT) and the current value.
